LEGO pris per del: vad är ett bra köp?

Av Nathan Brooks · 15 juli 2026 · 8 min läsning

Om du någonsin stått i en leksaksgång eller scrollat i en nätbutik och undrat om ett LEGO-set faktiskt är värt pengarna, är LEGO pris per del det snabbaste sättet att få ett svar. Det tar sitt listpris och delar det med antalet delar i lådan, vilket ger dig ett enda tal du kan jämföra mellan set av vitt skilda storlekar. Ett set med 300 delar och ett med 3 000 delar är omöjliga att jämföra på totalpris allena, men pris per del sätter dem på samma skala. I den här guiden bryter vi ner hur ett bra köp verkligen ser ut, varför den populära regeln "10 cent per del" bara tar dig halvvägs och hur du använder pris per del för att hitta både fynd och set med stark andrahandspotential.

Vad pris per del faktiskt betyder

Pris per del (ofta förkortat PPP) är enkel matematik: priset på seten delat med dess officiella antal delar. Ett set med 500 delar som kostar 50 dollar blir 10 cent per del. Ett set med 1 000 delar för 80 dollar blir 8 cent per del. Det andra seten är det bättre värdet på ren kostnad-per-kloss-basis, även om det kostar mer totalt.

Anledningen till att detta mått är så användbart är att det skalar bort psykologin i totalpriset. Ett set för 200 dollar känns dyrt, men om det rymmer 3 000 delar betalar du under 7 cent per del, vilket är utmärkt. Samtidigt landar ett set för 30 dollar med bara 150 delar på 20 cent per del, vilket är i det dyra spannet. PPP ger dig ett äpple-mot-äpple-tal så att du kan bedöma set rättvist oavsett hur stora eller små de är.

En snabb notering om noggrannhet: använd alltid det aktuella försäljningspriset, inte tillverkarens rekommenderade cirkapris (MSRP), när ett set är rabatterat. Ett set som sjunker från 100 dollar till 70 dollar under en rea ser sitt pris per del falla med 30 procent, och det är ofta skillnaden mellan ett medelmåttigt köp och ett bra.

Tumregeln "10 cent per del" och var den brister

Fråga runt i LEGO-communityt så hör du samma förkortning om och om igen: sikta på ungefär 10 cent per del. Som ett startfilter är det ett rimligt ankare. Till fullt butikspris ligger många standard-LEGO-set någonstans mellan 10 och 13 cent per del, så allt bekvämt under en tia per kloss tenderar att kännas som en vinst, och allt en bra bit över det förtjänar en andra titt.

Problemet är att 10-cents-regeln behandlar varje del som likvärdig, och delar är inte likvärdiga. Ett set kan vara fyllt med små 1x1-pluppar och små plattor som fyller ut antalet delar utan att tillföra mycket värde, vilket får dess pris per del att se konstlat attraktivt ut. Ett annat set kan innehålla stora specialiserade paneler, stora bottenplattor, tryckta element eller intrikata mekanismer som kostar mer att producera men som var för sig räknas som en enda del. Det seten kan ha ett "högt" pris per del och ändå vara ett fantastiskt köp.

Så behandla 10 cent som en grov magkänslekoll, inte en dom. Det är ett sätt att snabbt sortera set i "förmodligen okej", "misstänkt billigt" och "värt att undersöka", men det bör aldrig vara det enda talet du förlitar dig på.

Varför licensierade och stora set spelar efter andra regler

Två kategorier bryter konsekvent mot 10-cents-regeln, och att förstå varför räddar dig från att felbedöma bra set.

Licensierade set. Teman som Star Wars, Harry Potter, Marvel och andra varumärkeslinjer bär en licenskostnad som LEGO betalar till rättighetsinnehavaren. Den kostnaden bakas in i priset, så licensierade set ligger nästan alltid högre på pris per del än ett motsvarande icke-licensierat set. Ett Star Wars-set på 12 eller 13 cent per del kan fortfarande vara ett starkt köp inom sin kategori, även om ett City- eller Creator-set på samma tal skulle se överprissatt ut. Bedöm licensierade set mot andra licensierade set, inte mot hela katalogen.

Stora och komplexa set. Stora utställningsset, technic-byggen med motorer och kugghjul och modulbyggnader tenderar att inkludera fler stora, unika och tryckta delar. Dessa element höjer tillverkningskostnaden per del och kommer ofta med premiumlådor, tjockare instruktionshäften och minifigurer med exklusiva tryck. Ett flaggskeppsset med 2 500 delar kan ligga på 11 eller 12 cent per del, men kvaliteten och åtråvärdheten i det du får kan mer än rättfärdiga det.

Baksidan gäller också. Vissa set ser billiga ut per del just för att de är fyllda med utfyllnadsklossar. Ett lågt pris per del är inte automatiskt ett bra köp om bygget är tråkigt eller delarna är vanliga. Sammanhanget spelar alltid roll.

Att använda pris per del för att hitta fynd och andrahandspotential

När du väl förstår baslinjen blir pris per del ett praktiskt verktyg för två saker: att hitta fynd idag och att förutsäga värde imorgon.

Att hitta fynd. Draget är att jämföra ett sets aktuella pris per del mot dess typiska pris per del. Om ett set normalt säljs för 11 cent per del och en återförsäljare har det för 7 cent per del, är det en verklig rabatt värd att agera på, inte bara marknadsföring. Detta är exakt där ett index för pris per del hjälper: istället för att ögonmäta det kan du se hur ett sets aktuella värde står sig mot dess egen historik och mot liknande set. BrickGains upprätthåller ett index för pris per del som gör den jämförelsen åt dig, så att du kan skilja en genuin prissänkning från ett falskt "rea"-pris.

Andrahandspotential. Pris per del antyder också vilka set som behåller eller ökar i värde efter att de utgått. Set som redan var rikligt prissatta per del, särskilt licensierade och begränsade utställningsset, ökar ofta i värde när de lämnar hyllorna eftersom efterfrågan överlever utbudet. När du kan köpa ett snart utgått set till ett lågt pris per del idag köper du i praktiken under dess sannolika framtida golv. Att spåra det gapet mellan vad du betalade per del och vad marknaden betalar per del senare är kärnan i att behandla LEGO som en liten portfölj snarare än bara ett köp.

Ett praktiskt arbetsflöde ser ut så här: gör en lista över de set du gillar, kolla det aktuella priset per del för varje, jämför mot det typiska värdet och prioritera de som ligger en bra bit under sitt normala spann. Du kan kolla ett set gratis innan du köper för att se var det landar.

Genomräknade exempel

Siffror gör detta konkret. Här är några illustrativa exempel med runda tal.

Exempel 1: det ärliga mellanstora seten. Ett icke-licensierat Creator-set med 750 delar för 60 dollar är exakt 8 cent per del. Det är bekvämt under 10-cents-ankaret, delarna är varierade och det finns ingen licens som blåser upp priset. Detta är ett rent, odramatiskt bra köp.

Exempel 2: det licensierade flaggskeppet. Ett Star Wars-utställningsset med 2 000 delar för 240 dollar blir 12 cent per del. På den råa tumregeln ser det dyrt ut, men för ett stort licensierat set packat med tryckta och unika delar ligger det helt i linje med sin kategori. Om det sjunker till 200 dollar är du på 10 cent per del, vilket för den här typen av set är ett starkt köp och en kandidat att behålla sitt värde efter utgång.

Exempel 3: den utfyllda fyndfällan. Ett set med 1 200 delar för 84 dollar ser toppen ut på 7 cent per del, men om hälften av de delarna är små 1x1-pluppar och den färdiga modellen är liten, döljer det låga talet ett svagt bygge. Billigt per del betyder inte alltid tillfredsställande att äga.

Exempel 4: rean som spelar roll. Ett set med 1 000 delar normalt för 100 dollar (10 cent per del) nedsatt till 65 dollar är nu 6,5 cent per del. Den prissänkningen på 35 procent förvandlar ett medelbra köp till ett tydligt, och det är den sortens gap BrickGains index för pris per del är byggt att synliggöra. Du kan använda indexet för pris per del för att jämföra ett set mot dess typiska värde innan du binder dig.
